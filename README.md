# みんなのクイズ大会

ログインなしで、みんなでスマホから遊べる4択早押しクイズです。

- ルーム主が「ルームを作る」と4けたのルーム番号が出ます。参加者は番号（または参加リンク）とニックネームで参加します
- 問題数（5・10・15・30問）と制限時間はルーム主がロビーで決めます
- ルーム主が「はじめる」を押すと、全員の投票（多数決）でルールが決まります。全員が「準備OK」を押したら締め切りで、同じ票数ならランダムです（ルーム主は待たずに締め切ることもできます）。決まったルールはスロットのように1つずつ発表されます
  - 形式：個人戦 / チーム戦（ランダムで赤・青の2チームに分かれる。チーム得点はメンバーの平均点）
  - モード：通常（全員が答える。速く正解するほど高得点）/ 早押し（いちばん早く正解した人だけ1000点。まちがえるとお手つき）
  - 回答方式：4択 / タイピング（答えを入力。ひらがな・カタカナ・漢字どれでもOK）/ 混合
  - ジャンル
  - 難易度：初級 / 中級 / 上級（選んだ難易度の問題を優先して出題。足りないときは近い難易度から補います。なぞなぞは難易度共通）
  - 多数派問題：回答方式がタイピングか混合で、モードが通常のときに、正解のない問題がときどき（1問ごとに2割の確率。1問目は除く）まざります。答えを自由に入力し、いちばん多かった答え（2人以上。同数ならすべて）を入力した人が1000点
  - 特殊ルール：なし / ベット（答えるときに×2・×3を賭ける。外れると500点・1500点減る）/ イベント（ときどき得点2倍・逆転チャンス・先着ボーナス・ハイリスクの問題。最終問題は得点3倍）/ ベット＋イベント
- 答え合わせのあと、5秒で自動的に次の問題へ進みます（ルーム主は「すぐ次へ」で早められます）
- ルーム主も一緒に回答できます
- 正解はサーバーの中だけにあり、答え合わせの瞬間まで誰の画面にも送られません
- 終盤（最後の約3割の問題）は合計点・順位・チーム得点がかくされ、最後の結果発表で明かされます。個人戦は3位から順に、チーム戦は2本のグラフが伸びていく演出で発表します
- 名前の横にアイコンと色を付けられます。ひとことチャット（出題中は送信不可）と、観戦での参加にも対応しています
- 友達がいなくても、ルーム主がNPC（よわい・ふつう・つよい、最大7人）を入れれば1人で対戦できます（NPCは投票しません）

追加ライブラリは不要です（Node.js 18 以上だけで動きます）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `server.js` | サーバー（ルーム、出題、採点） |
| `questions.js` | 問題とジャンル |
| `updates.json` | 最初の画面に出るアップデート情報 |
| `public/index.html` | 遊ぶ画面 |
| `package.json` | 起動コマンドの設定 |

## 自分のパソコンで試す

```
node server.js
```

ブラウザで http://localhost:3000 を開きます。同じWi-Fiのスマホからは `http://<パソコンのIPアドレス>:3000` で参加できます。

## インターネットに公開する（Render の無料プラン）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードします
2. https://render.com にGitHubアカウントで登録します
3. 「New」→「Web Service」を選び、さっきのリポジトリを選びます
4. 次のように設定します
   - Language: `Node`
   - Build Command: `npm install`（何もインストールされませんが、そのままで大丈夫です）
   - Start Command: `npm start`
   - Instance Type: `Free`
5. 「Deploy」を押します。数分で `https://〇〇.onrender.com` のURLができるので、それを友達に送れば遊べます

無料プランの注意点

- しばらく誰も使わないとサーバーが眠ります。次に開いたとき、起動に1分ほどかかります
- サーバーが眠ったり再起動したりすると、作ってあったルームは消えます（遊ぶ前に開いておけば大丈夫です）

## 問題を増やす

`questions.js` の各ジャンルに、次の形で1行足します。**`c` の1つ目に正解**を書いてください。出題のときに選択肢は自動でシャッフルされます。

```js
{ t: "問題文", c: ["正解", "ハズレ1", "ハズレ2", "ハズレ3"] },
```

タイピングでも出したい問題には `k` をつけます。`k` には、正解として認めるほかの書き方（読みがななど）を書きます。`c` の1つ目はいつでも正解になるので、ほかの書き方がなければ `k: []` で大丈夫です。

```js
{ t: "日本でいちばん高い山は？", c: ["富士山", "北岳", "槍ヶ岳", "白山"], d: 1, k: ["ふじさん"] },
```

問題ごとの `d` は難易度です（1=かんたん、2=ふつう、3=むずかしい）。`d` を書かないと「ふつう」として扱われます。

多数派問題は、`questions.js` の `MAJORITY` に足します。`a` には、よくある答えを `[表示する答え, ほかの書き方…]` の形で並べます。ここに書いた書き方どうしは同じ答えとして数えます（ひらがな・カタカナ・全角半角のちがいは自動で同じとみなすので、漢字の読みなどを書いておきます）。ここにない答えも、同じ書き方どうしでまとめて数えます。

```js
{ t: "好きな季節は？", a: [["春", "はる"], ["夏", "なつ"], ["秋", "あき"], ["冬", "ふゆ"]] },
```

新しいジャンルを作るときは、`GENRES` に `{ id: "anime", name: "アニメ", note: "説明" }` を足し、`BANK` に同じ `id` の問題リストを足します。

## アップデート情報を書く

`updates.json` のいちばん上に1件足すと、最初の画面の「アップデート情報」に出ます（いちばん上に NEW がつきます）。

```json
{
  "date": "2026-11-10",
  "title": "新しいジャンルを追加",
  "items": ["スポーツのジャンルを追加しました"]
},
```

## 更新しても遊びつづけられるしくみ

サーバーを更新（再起動）すると、メモリにあるルームは消えてしまいます。そこでルームの状態を暗号化して参加者のブラウザに預けておき、再起動後に返してもらってルームを元に戻します。

- 出題中の問題は、残り時間と答えをそのままに続きます（止まっていたあいだの時間は数えません）
- 開いている画面は、新しい版になると自動で読みこみ直します（入力中の答えは残ります）
- 再起動のときにルームの画面を1人も開いていなかった場合は、そのルームは再開できません

### 暗号の鍵を登録する（おすすめ）

Render の画面で、サービスの左メニュー「Environment」→「Add Environment Variable」から、次の1つを登録して保存します。

- Key: `QUIZ_SECRET`
- Value: 長くてランダムな文字列（だれにも教えない）

登録しなくても動きますが、登録しておくと、預けたデータの中身をほかの人が読んだり書きかえたりできなくなります。

## 意見箱（Google フォームで受け取る）

サイト内の「ご意見・不具合の報告」から送られた内容は、Google フォームに転送されます。

1. Google フォームで新しいフォームを作り、質問を4つ作る（形式はすべて「記述式」、内容だけ「段落」）
   - 種類 / 内容 / 名前 / 情報
2. 右上の「︙」→「事前入力したURLを取得」を開き、4つの欄にそれぞれ `KIND`・`TEXT`・`NAME`・`INFO` と半角で入力して「リンクを取得」→「リンクをコピー」
3. Render のサービス画面「Environment」で、Key に `FEEDBACK_FORM_URL`、Value にコピーしたリンクを登録して保存
4. フォームの「回答」タブで、スプレッドシートへのリンクや、新しい回答のメール通知を設定できます

登録していないあいだは、届いた意見は Render の「Logs」に表示されるだけです（再起動で消えます）。
同じ回線からは10分に3件まで送れます。
